Encrypt saved data

When on, everything saved on this PC is scrambled with your software password, so someone who copies the data folder cannot read it. The password is also asked every time the software opens.

If you forget the password, the data cannot be opened by anyone. Make a backup first, and keep the password written down.

Live sync with Google Drive

One-time setup (about 5 minutes, free). Do this once, then use the same Client ID on the PC and the phone:

  1. Open console.cloud.google.com and create a project.
  2. APIs and Services, Library: enable Google Drive API.
  3. OAuth consent screen: type External, open Data access and add the scope .../auth/drive.appdata (also add drive.file if you like), then press Publish app (so the sign-in does not expire after 7 days).
  4. Credentials, Create credentials, OAuth client ID, type TVs and Limited Input devices.
  5. Paste the Client ID and Client secret below, press Sign in with Google, then enter the code on google.com/device with the Google account you want to use. Sign in with the same Google account on the PC and the phone.

Use the same software password on every device. The cloud copy is encrypted with it.
