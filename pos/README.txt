POS - website version
=====================
Upload ALL the files in this folder to your website (for example into a folder called "pos"):
  index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png
Then open  https://your-website.com/pos/  in a browser.

Your website MUST use https:// (the software needs it to work and to check the subscription).

How it works
- The website version also needs a subscription. Each browser gets its own Device ID
  (shown on the subscribe screen). Add that ID in your admin panel and publish, like for the PC and phone apps.
- The data is saved inside that browser on that computer. Clearing the browser's site data
  removes it, so keep a backup or use the PC/phone app for important work.
- On a phone or PC the customer can choose "Install app" / "Add to Home screen" in the browser menu.

Free hosting options: GitHub Pages (Settings > Pages), Netlify, Cloudflare Pages, or your normal hosting (cPanel > public_html).
